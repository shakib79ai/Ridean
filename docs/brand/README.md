# Ridean brand kit

The Ridean logo: a gold car outline with a wheel, the gold **Ridean** wordmark and the slogan **RIDE | TRANSFER | RENT** in white, on deep emerald.

| Folder | Files |
|---|---|
| `logo/` | Full logo and logo without slogan, transparent PNG for dark and for light backgrounds; car mark; logo on green and on cream (PNG + JPEG) |
| `social/` | Profile pictures 1080×1080, covers for Facebook (1640×624), X (1500×500), LinkedIn (1584×396), YouTube (2560×1440), story (1080×1920), website share image (1200×630) |
| `app-icons/` | App icon 1024, Android adaptive foreground, PWA icons 192/512/maskable, Apple touch icon 180 |
| `favicon/` | `favicon.ico` (16/32/48) and PNG favicons |

Colours: emerald `#112E18`, gold `#E9B949` (gradient `#FBE08C` → `#C08C22`), white slogan `#FFFFFF`; on light backgrounds the slogan is `#0E3B22`.

Where it is used: website, PWA and admin headers and sign-in pages (`public/brand/`), Next.js `favicon.ico` / `icon.png` / `apple-icon.png` / `opengraph-image.png`, PWA manifest icons, and the Flutter app (`assets/images/logo*.png`, launcher icons from `assets/brand/` via `flutter_launcher_icons`).
