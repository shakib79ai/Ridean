# Screens

Screenshots of every page, captured from the running code on this branch (sample suppliers, test payments). Open each `index.html` in a browser.

| Folder | What | Pages |
|---|---|---|
| [website](website/index.html) | Customer website (`apps/website`) | 30 |
| [pwa](pwa/index.html) | Installable phone app (`apps/pwa`) | 27 |
| [app](app/index.html) | Flutter app, iPhone and Android (`apps/mobile`) | 27 |
| [admin](admin/index.html) | Admin panel (`apps/admin`) | 16 |

The Flutter screens are regenerated by the **Mobile screens** GitHub workflow, which pushes fresh captures to the `mobile-screens` branch.
